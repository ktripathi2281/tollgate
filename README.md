# Tollgate

An OpenAI-compatible LLM gateway in Go with payments-grade spend control: per-key rate limits, hold-and-settle budgets in integer micro-USD, idempotency keys, and a reconcile command.

Work in progress. See [docs/PROGRESS.md](docs/PROGRESS.md) for the current state and [docs/BRIEF.md](docs/BRIEF.md) for the design.
